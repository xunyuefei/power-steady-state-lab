# 电力系统稳态分析 · 高精度手算校验台 (Power Steady-State Lab)

> ⚡ **专为华北电力大学（811/812）等高校电气工程考研专业课与电网工程计算打造的“零记忆负担、防错、高精度快速校验台”。**

---

## 🌟 核心解决痛点

在《电力系统稳态分析》手算大题推导过程中，考生的失分往往不是不懂原理，而是死在以下细节陷阱：
1. **量纲未统一**：kW、MW、kVar、MVar、Ω 与 μS 混用导致数量级错误。
2. **共轭遗漏**：环网分流、循环功率计算中忘记对阻抗或电压差取复数共轭（$Z^*$）。
3. **容量未折算**：三绕组变压器短路试验在非 100% 试验容量下进行时，铜损漏乘 $(S_N / S_{test})^2$。
4. **充电功率符号混淆**：电网线路对地电纳发出容性无功（注入系统），节点功率平衡中漏掉 $-jQ_c$ 扣除。
5. **手算错步难排查**：普通计算器只给终值，草稿纸上一旦对不上答案，不知道错在第几步。

## 🚀 核心功能与亮点

- **47 核心公式全量卡片式独立手算校验**：
  1. **电压降落与相角差 (#06)**：支持 **已知末端求首端（逆流加法·升压推演）**、**已知首端求末端（顺流减法·降压推演）** 与 **首端电压与末端负荷双解**，彻底告别单向加法限制！
  2. **线路损耗与对地充电 (#03, #05)**：串联支路损耗 $\Delta P, \Delta Q$、单侧并联半数充电功率 $Q_c/2$。
  3. **多节点环网潮流分布 (#07)**：严格共轭力矩分流、**【有功分界点】与【无功分界点】智能侦测**。
  4. **两端供电/闭式环网循环功率 (#08)**：**内置变压器实际变比与分接头自动折算**（无需草稿纸反复归算，直接输入母线电压与变压器额定分接头即可自动折算 $d\dot{U}$ 并求得 $\dot{S}_C$ 复数循环功率及潮流流向）！
  5. **自然功率与波阻抗 (#11)**：波阻抗、自然功率与高压线路功率特性。
  6. **双绕组/三绕组变压器参数与损耗 (#01, #04, #13, #14)**：全电压侧归算、容量折算与不变/可变损耗分离。

- **学术级数学公式渲染 (KaTeX)**：标准教材级矢量数学公式展示，告别代码字符。
- **草稿纸对齐分步推导**：展示每一步套入公式的代入值与分步结果，秒查草稿错漏。
- **华电 811/812 历年考研真题库**：内置多组经典真题与教材例题，一键切换回填。
- **单位交互直切**：支持 `kW ⇄ MW`、`kVar ⇄ MVar` 自由点击切换，自动换算。
- **电气拓扑与矢量图解**：动态相量图、环网分界点拓扑图、变压器星型等效图全量呈现。
- **深色电网工业风 / 浅色自习室纸质风** 一键切换。

## 🌐 部署至 GitHub Pages

本项目已配置好了 GitHub Actions 自动化部署工作流（位于 `.github/workflows/deploy.yml`）。

### 部署步骤：

1. **创建 GitHub 仓库**：在 GitHub 上新建一个仓库（例如命名为 `power-steady-state-lab`）。
2. **关联本地代码并推送**：
   ```bash
   git init
   git add .
   git commit -m "feat: 初次提交电力系统稳态分析手算校验台成品"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/power-steady-state-lab.git
   git push -u origin main
   ```
3. **开启 GitHub Pages**：
   - 打开 GitHub 仓库页面，点击 **Settings（设置）** -> **Pages（页面）**。
   - 在 **Build and deployment -> Source** 下拉菜单中选择 **GitHub Actions**。
4. **访问线上成品**：
   - 稍等 1~2 分钟，GitHub Actions 构建完成后，即可通过以下公开链接直接访问：
   - `https://<你的用户名>.github.io/power-steady-state-lab/`
